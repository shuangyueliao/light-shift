# Light Shift · 霓虹熄灯

Free single-file HTML5 puzzle game. Classic Lights Out on a 5x5 neon grid:
tap a tile and it flips together with its neighbours — switch off every
light to win. Guaranteed-solvable levels, star ratings, one hint per board.

**Play:** https://shuangyueliao.github.io/light-shift/

- Level mode (move limit + stars) and endless fewest-moves mode
- Mouse / touch / keyboard (arrows + Enter, H hint, M mute), procedural WebAudio pentatonic sounds
- Procedural neon visuals, no dependencies
